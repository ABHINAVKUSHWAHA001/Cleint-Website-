# ANYA VISUALS — HTML, CSS & JavaScript website

## Files
- `index.html` — Home page
- `about.html` — About Us
- `services.html` — Services
- `portfolio.html` — Portfolio gallery
- `films.html` — Films & Reels
- `booking.html` — Booking enquiry form
- `contact.html` — Contact details and location
- `styles.css` — Shared responsive styling
- `script.js` — Mobile menu and booking enquiry interactions
- `assets/anya-visuals-homepage.png` — hero visual reference

## Run locally
1. Extract the ZIP file.
2. Keep every HTML file, `styles.css`, `script.js`, and the `assets` folder together in one folder.
3. Open `index.html` in a browser, or use VS Code Live Server for a better local preview.

## Important before publishing
- Portfolio images are sample external images; replace them with your own licensed/original work.
- The enquiry form opens WhatsApp or the user's email app. It does not automatically send messages or save submissions to a database.
- The main WhatsApp enquiry defaults to +91 76189 24280.
- Google Fonts and external sample photos require an internet connection.
- The exact street address and business hours were not provided, so they are not invented.
